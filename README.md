# Média de Notas em Python

Programa simples desenvolvido em Python para calcular a média de duas notas informadas pelo usuário.

## Funcionalidades

- Receber duas notas
- Calcular a média aritmética
- Informar a média do aluno
- Exibir situação de aprovação ou reprovação

## Exemplo

Digite a primeira nota: 8
Digite a segunda nota: 6

A sua nota foi 7.0!!
Aprovado!!

## Tecnologias Utilizadas

- Python

## Conceitos Praticados

- Entrada de dados
- Variáveis
- Operadores aritméticos
- Estruturas condicionais (if/else)
- Saída de dados
